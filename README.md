# EngageAI – Social Media Engagement Predictor

## Project Overview

EngageAI is a machine learning-based application designed to predict social media post engagement. It aims to help content creators and social media teams estimate the potential performance of posts before publishing.

The application provides an interface for engagement prediction, dataset exploration, interactive analytics, and machine learning model information.

## Live Demo

Explore the application: https://engage-wise-predict.lovable.app/

## Key Features

* **Engagement Prediction:** Estimates likes, comments, and shares based on post information.
* **Machine Learning:** Uses a Random Forest model for engagement forecasting.
* **Dataset Exploration:** Provides an interface to explore social media post data.
* **Interactive Analytics:** Visualizes engagement distributions, trends, and relationships.
* **Engagement Forecasting:** Supports comparisons of potential posting times.
* **Model Information:** Presents information about the model, preprocessing pipeline, and performance metrics.

## How It Works

1. Enter the relevant social media post information.
2. Submit the inputs to the prediction interface.
3. View the predicted engagement metrics.
4. Explore the analytics dashboard to understand engagement patterns.
5. Review the model information and evaluation metrics.
